## บทพูดต่อเนื่อง (อ่านตามได้เลย)

อ่านหนังสือคนเดียว เหงา เบื่อ แล้วก็เลิก ทุกคนเคยเป็น วันนี้เรามีทางออก

นี่คือ I LOVE TCAS โรงเรียนที่อยู่ในเว็บ เพื่อนทั้งโรงเรียนอยู่ในนั้น เปิดทิ้งไว้ได้ทั้งวัน

นั่งลง กดเริ่ม แค่นั้น ทุกนาทีที่อ่านจริงกลายเป็นคะแนนของโรงเรียนคุณ และบอร์ดนี้บอกว่าอีกกี่วันถึงวันสำคัญของ TCAS วันจริง ข้อมูลจริง

สร้างด้วย React กับ Phaser ส่วนหลังบ้านคือ Firebase และ Cloud Functions ข้อมูล TCAS ดึงผ่าน Vercel ข้างใต้มีความเชื่อข้อเดียว เซิร์ฟเวอร์ตัดสินทุกอย่าง ไม่ใช่ผู้เล่น

ดูโค้ดนี้ เช็กอินห่างเกิน 35 นาที ไม่นับ วันละไม่เกินแปดชั่วโมง ใครก็แก้ตัวเลขไม่ได้ ส่วนอันดับ หารด้วยคนทั้งโรงเรียน โรงเรียนใหญ่ไม่ได้เปรียบ เรียบง่าย และยุติธรรม

ทุกการตัดสินใจจดไว้ก่อนเขียนโค้ด และเทสต์กว่า 1,200 ข้อคอยเฝ้าอยู่

ทั้งหมดนี้ เล่นได้ตอนนี้

## ก่อนกดอัด (เช็กลิสต์ 2 นาที)

1. เปิดหน้า GitHub ให้เห็น README ใหม่ (ถ้ายังเป็นฉบับเก่า รีเฟรช หรือเช็กว่า push แล้ว)
2. เว็บแอปล็อกอินแล้ว กดเข้าโรงเรียนจนเห็นห้อง ("ห้องรวม #1")
3. กดเริ่มโฟกัสทดสอบหนึ่งรอบก่อน เพราะยังไม่เคยลองบนเว็บจริง ถ้าแผงโฟกัสขึ้น error ให้ตัดฉากโฟกัสออก เหลือแค่เดินในแผนที่กับบอร์ด
4. ซูมเบราว์เซอร์ให้ตัวอักษรโค้ดอ่านออก ปิดแจ้งเตือนและแท็บอื่น
5. ซ้อมอ่านจับเวลาหนึ่งรอบ ถ้าเกิน 2 นาที ตัดประโยคแผนภาพสถาปัตยกรรมออกก่อน
