## บทพูดต่อเนื่อง

เวลาเตรียมสอบ เรามักอ่านหนังสือคนเดียวแล้วเบื่อ เลยทำเกมโรงเรียนให้ทุกคนมาอ่านหนังสือด้วยกัน เปิดทิ้งไว้ได้ทั้งวัน

ในเกม เรานั่งโต๊ะแล้วกดเริ่มอ่าน เกมจะถามทุก 25 นาทีว่ายังอยู่ไหม ถ้าอยู่ถึงนับเวลาให้ เวลาของทุกคนในโรงเรียนรวมกันเป็นอันดับของโรงเรียน ส่วนบอร์ดโรงอาหารบอกวันสำคัญของ TCAS จริง ๆ

เรื่องสำคัญที่สุดคือกันโกง เวลากับคะแนนให้เซิร์ฟเวอร์นับ ไม่ให้เครื่องของผู้เล่นนับเอง ใครจะได้แก้ตัวเลขไม่ได้

ระบบมีสามส่วน ส่วนหน้าเว็บที่คนเล่น ส่วนหลังบ้านที่นับเวลาและคะแนน และส่วนดึงข้อมูล TCAS กับข่าวค่ายจากข้างนอก

โค้ดตรงนี้คือหัวใจ ถ้าเช็กอินห่างเกิน 35 นาที เวลาช่วงนั้นไม่นับ วันหนึ่งนับได้สูงสุดแปดชั่วโมง ส่วนอันดับ เราเอาเวลารวมหารด้วยคนทั้งโรงเรียน โรงเรียนใหญ่เลยไม่ได้เปรียบ

ก่อนเขียนโค้ด เราจดเหตุผลของทุกการตัดสินใจไว้ แล้วเขียนเทสต์กว่า 1,200 ข้อ คอยเช็กว่าไม่มีอะไรพัง

ทั้งหมดนี้เล่นได้จริงบนเว็บแล้ว

## ก่อนกดอัด (เช็กลิสต์ 2 นาที)

1. เปิดหน้า GitHub ให้เห็น README ใหม่ (ถ้ายังเป็นฉบับเก่า รีเฟรช หรือเช็กว่า push แล้ว)
2. เว็บแอปล็อกอินแล้ว กดเข้าโรงเรียนจนเห็นห้อง ("ห้องรวม #1")
3. กดเริ่มโฟกัสทดสอบหนึ่งรอบก่อน เพราะยังไม่เคยลองบนเว็บจริง ถ้าแผงโฟกัสขึ้น error ให้ตัดฉากโฟกัสออก เหลือแค่เดินในแผนที่กับบอร์ด
4. ซูมเบราว์เซอร์ให้ตัวอักษรโค้ดอ่านออก ปิดแจ้งเตือนและแท็บอื่น
5. ซ้อมอ่านจับเวลาหนึ่งรอบ ถ้าเกิน 2 นาที ตัดประโยคแผนภาพสถาปัตยกรรมออกก่อน

## ข้อควรระวัง

- รางวัลกรอกเอง ผมไม่มีข้อมูล ห้ามเดา
- ถ้าจะโชว์หน้าอันดับโรงเรียน ใช้ข้อมูลจากการเล่นจริงเท่านั้น ในบทนี้ไม่ได้โชว์อันดับ เพื่อเลี่ยงหน้าว่าง
