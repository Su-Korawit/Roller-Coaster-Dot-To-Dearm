## บทพูดต่อเนื่อง

อ่านหนังสือคนเดียว เหงา เบื่อ แล้วก็เลิก ทุกคนเคยเป็น วันนี้เรามีทางออก

นี่คือ I LOVE TCAS โรงเรียนที่อยู่ในเว็บ เปิดทิ้งไว้ทั้งวัน เพื่อนทั้งโรงเรียนอยู่ในนั้น

นั่งลง กดเริ่ม แค่นั้น เกมนับเวลาให้ และทุกนาทีที่อ่านจริง กลายเป็นคะแนนของโรงเรียนคุณ

และเมื่ออ่านเสร็จ บอร์ดบอกว่าอีกกี่วันถึงวันสำคัญของ TCAS วันจริง ข้อมูลจริง

ข้างใต้มีความเชื่อข้อเดียว เซิร์ฟเวอร์ตัดสินทุกอย่าง ไม่ใช่ผู้เล่น ใครก็โกงไม่ได้

ดูโค้ดนี้ เช็กอินห่างเกิน 35 นาที ไม่นับ วันละไม่เกินแปดชั่วโมง อันดับหารด้วยคนทั้งโรงเรียน โรงเรียนใหญ่ไม่ได้เปรียบ เรียบง่าย และยุติธรรม

ทุกการตัดสินใจจดไว้ก่อนเขียนโค้ด และเทสต์กว่า 1,200 ข้อคอยเฝ้าอยู่

ทั้งหมดนี้ เล่นได้ตอนนี้

**[รางวัล: กรอกเอง]** I LOVE TCAS อ่านหนังสือ แต่ไม่ต้องอ่านคนเดียว

### เคล็ดลับการพูดแบบ Jobs
- พูดช้า หยุดหนึ่งจังหวะหลังทุกประโยคสั้น ปล่อยให้ภาพทำงาน
- ฉากโค้ด หยุดพูดสองวินาทีให้คนอ่านโค้ดก่อน แล้วค่อยชี้ทีละบรรทัด
- อย่าอธิบายทุกอย่าง เลือกโชว์สิ่งที่เห็นแล้ว "ว้าว" แล้วเลื่อนต่อ

## ก่อนกดอัด (เช็กลิสต์ 2 นาที)

1. เปิดหน้า GitHub ให้เห็น README ใหม่ (ถ้ายังเป็นฉบับเก่า รีเฟรช หรือเช็กว่า push แล้ว)
2. เว็บแอปล็อกอินแล้ว กดเข้าโรงเรียนจนเห็นห้อง ("ห้องรวม #1")
3. กดเริ่มโฟกัสทดสอบหนึ่งรอบก่อน เพราะยังไม่เคยลองบนเว็บจริง ถ้าแผงโฟกัสขึ้น error ให้ตัดฉากโฟกัสออก เหลือแค่เดินในแผนที่กับบอร์ด
4. ซูมเบราว์เซอร์ให้ตัวอักษรโค้ดอ่านออก ปิดแจ้งเตือนและแท็บอื่น
5. ซ้อมอ่านจับเวลาหนึ่งรอบ ถ้าเกิน 2 นาที ตัดประโยคแผนภาพสถาปัตยกรรมออกก่อน
