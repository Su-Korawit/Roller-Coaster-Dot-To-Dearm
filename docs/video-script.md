## บทพูดต่อเนื่อง

นักเรียนมัธยมมีเครื่องมือเตรียมสอบเยอะ แต่ไม่มีเหตุผลให้เปิดทุกวัน เราเลยสร้าง I LOVE TCAS โรงเรียนพิกเซลที่เปิดทิ้งไว้ได้ทั้งวัน

แต่ละโรงเรียนมีห้องของตัวเอง นั่งโต๊ะ กดโฟกัส ระบบเช็กอินทุก 25 นาที นับเฉพาะเวลาที่อยู่หน้าจอจริง เอาไปจัดอันดับโรงเรียนรายสัปดาห์ บอร์ดโรงอาหารแสดงปฏิทิน TCAS70 จริง

หลักการแรกคือเซิร์ฟเวอร์เป็นผู้ตัดสินทุกอย่างที่มีมูลค่า ทั้ง XP เวลา และอันดับ ไคลเอนต์ส่งตัวเลขมาเองไม่ได้

โครงสร้างแบ่งสามส่วน เบราว์เซอร์ที่ใช้ React กับ Phaser, Firebase ที่มี Cloud Functions คิดทุกอย่างที่สำคัญ และ Vercel ที่ดึงข้อมูล myTCAS กับข่าวค่าย

โค้ดส่วนสำคัญคือฟังก์ชันนี้ นับเวลาเฉพาะช่วงระหว่างเช็กอินสองครั้งที่สั้นพอให้เชื่อ ห่างเกิน 35 นาทีไม่นับ วันละไม่เกินแปดชั่วโมง ส่วนอันดับหารด้วยสมาชิกทั้งโรงเรียน โรงเรียนใหญ่เลยไม่ได้เปรียบเพราะจำนวนคน

เราเขียนการตัดสินใจเป็น ADR ก่อนลงโค้ด แยกตรรกะออกจากฐานข้อมูล แล้วเทสต์ครบ มีกว่า 1,200 ข้อ

## ก่อนกดอัด (เช็กลิสต์ 2 นาที)

1. เปิดหน้า GitHub ให้เห็น README ใหม่ (ถ้ายังเป็นฉบับเก่า รีเฟรช หรือเช็กว่า push แล้ว)
2. เว็บแอปล็อกอินแล้ว กดเข้าโรงเรียนจนเห็นห้อง ("ห้องรวม #1")
3. กดเริ่มโฟกัสทดสอบหนึ่งรอบก่อน เพราะยังไม่เคยลองบนเว็บจริง ถ้าแผงโฟกัสขึ้น error ให้ตัดฉากโฟกัสออก เหลือแค่เดินในแผนที่กับบอร์ด
4. ซูมเบราว์เซอร์ให้ตัวอักษรโค้ดอ่านออก ปิดแจ้งเตือนและแท็บอื่น
5. ซ้อมอ่านจับเวลาหนึ่งรอบ ถ้าเกิน 2 นาที ตัดประโยคแผนภาพสถาปัตยกรรมออกก่อน

## ถ้าเวลาไม่พอจริง ๆ (ตัดเหลือ 60 วินาที)

- รางวัลกรอกเอง ผมไม่มีข้อมูล ห้ามเดา
