# 0029 — OS core apps (Goal, Habit, Reading, Community, Secretary) and Store reviews

Status: accepted

## Context
The OS shell (ADR for the OS at ilovetcas.com) had only the Store. The product brief (hand-drawn, 2026-11-07) asks for five core apps for TCAS round-3 students and a Store that shows app details and reviews, plus links to useful websites.

## Decision
- **One synced store** `useLifeStore` (Goal target + exam date + scores, plan tasks, habits, books, reading log) cached in localStorage and synced to `users/{uid}.os` through `createFirestoreSync` (debounced). `ownerUid` + `adoptUser()` clears the cache when another account signs in. `users/{uid}.osRoomId` (top-level, derived from faculty + major) lets security rules decide chat-room membership.
- **Planner** is deterministic (`src/os/studyPlan.js`: weighted round-robin by score gap, 15-minute units, max 120 days). The AI (Gemini via `geminiClient`) only adds a Thai strategy note and one tip per subject (`src/services/aiStudyPlan.js`); if it fails the plan is still produced.
- **Community** rooms: `osRooms/{roomId}/messages`, roomId = faculty + major (any university) or `general`. Reading leaderboard: `osReading/{uid}`, group board = same `roomId`. Reviews: `osAppReviews/{appId}_{uid}`, one per user, 1-5 stars, ≤500 chars.
- **Store websites** are registry entries with `url` + `logo`; they open in a new tab (most sites refuse embedding). Logos were fetched from the sites' own icons and converted to 256px webp.
- The five core apps are `defaultInstalled` (one-time persist migration v1); the user can still remove them.
- App icons for the five apps are pixel art generated by code (Soft Pixel palette) instead of via ChatGPT, so the theme is exact.

## Considered options
- Per-device only data (rejected: the brief wants it in the database and shared across apps).
- Letting the AI produce the whole schedule (rejected: unpredictable, breaks without quota; kept as an optional note).
- Embedding the Phaser study-room in Reading (deferred: the Reading app is a timer + avatar room that feeds Habit and the leaderboard).

## Consequences
- Needs `firebase deploy --only firestore:rules` (queued in `.lv/pending-deploys.json`) before reviews, chat and the leaderboard work in production.
- Goal data is visible in the users doc (readable by any signed-in user, as today's other fields); keep nothing sensitive in `os`.
- Reading does not yet reuse the 3D/Phaser room or the Functions-owned Leaves.

## Update 2026-11-07 (Goal as a full app, university apps, Report)
- **Every item is an app, not a feature.** Goal, Report and each university have their own tabs/flows inside the window (Goal: goals / scores / plan; University: home / programmes / website; Report: board / send / mine).
- **Goal sources.** MyTCAS (`/api/mytcas`) is the primary source for university → faculty → programme and the round-3 score weights. Only when MyTCAS has no match does the picker offer TCAS Starter (`/api/tcasin`, tcas.in.th HTML parsed in `api/tcasinParse.js`; unofficial, may be last year's data, flagged in the UI and on the goal card). The advisor (`aiAdvisor.js`) only suggests names; they are resolved against MyTCAS.
- **Up to 5 goals** (`goals`, `primaryGoalId` in `useLifeStore`, synced in `users/{uid}.os`). The primary goal drives `target` (Habit, Community room, Secretary) and the score list; scores the student typed stay, goal scores are swapped, "mine" is kept by subject. MyTCAS rarely publishes a minimum per subject: when `min_total_score` is missing the target defaults to 60 and is marked "~" (estimated).
- **University apps**: 91 registry entries generated from `src/data/universityApps.js` (92 institutions in myTCAS; KU keeps its original `link-kuadmission` tile). Goal recommends the goal's university app + MyTCAS + TCAS Starter with install buttons.
- **Report** (`osRequests`, `osRequestVotes`): requests for apps/websites, one vote per user per request, only a super-admin changes status. Rules + tests added (83 rules tests pass). Needs `firebase deploy --only firestore:rules` (queued).
- **Intro scenes** now exist for Goal, Habit, Community, Reading, Secretary, Report. Code-drawn for now; ChatGPT brief 008 covers banners + storyboard frames to replace them.
