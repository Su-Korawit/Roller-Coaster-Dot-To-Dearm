# 0021 — Soft Pixel visual system

**Status:** accepted
**Date:** 2026-10-16

## Context

ADR-0019 gave the app a cozy parchment/wood "Sprout Lands" chrome. In practice the
reused Sprout Lands tiles repeat across the map, cannot tell one faculty from
another, and the warm-parchment UI is not the clean, minimal, modern look the product
now needs (white, minimal, still unmistakably a pixel game, good enough to post on a
studygram account). The v2 direction (study room, hotbar, Open House campus, Plan —
`docs/superpowers/specs/2026-10-16-ilovetcas-v2-overview.md`) needs one visual
language across every surface.

## Decision

Adopt **Soft Pixel** (spec: `docs/superpowers/specs/2026-10-16-soft-pixel-redesign-design.md`).

- **Tokens:** white / mist surfaces; outline purple `#5c4e92` (the MBTI sprites' outline)
  as `--color-line`/`--color-brand`/`--color-edge`; ink `#2B2550`; six faculty zone
  colours each with `-soft`/`-deep`; radii 8/12/20; hard blur-free shadow
  `3px 3px 0 #5c4e92`. Legacy token names are re-pointed (not renamed) so ~1,900 utility
  usages restyle with no JSX edits; they are renamed per screen group later.
- **Values deviate from the spec's first draft to meet WCAG AA text contrast** (on white, and on mist / brand-soft / the zone tints after final review): `ink-soft` `#686288`, `zone-health-deep` `#9D5753`, `zone-arts-deep` `#955A7D`, `zone-earth-deep` `#3F7750`, plus three below:
  `danger` `#C2413D` (spec `#D9534F`, 3.96:1), `accent-pink` `#B8467F` (art pink fails as
  text), and the business-zone deep tone `#8A6420`. `warn`, `good`, `leaf`, `lime` are
  documented as background-only.
- **Type:** Chakra Petch (Thai + Latin, squared) for game UI labels and numbers
  (`.pixel-font`); Noto Sans Thai for body; Press Start 2P only for Latin wordmarks via
  `.wordmark-font`.
- **Surfaces:** `.px-card/-btn/-slab/-sheet/-pressed/-input` are canonical; `.neo-*` stay as
  aliases until their usages migrate (Part B).
- **Art:** generated by code (`scripts/art/`, `sharp`), palette-linted, human-reviewed on
  contact sheets; integer scaling; rounded forms from ellipses.
- **Motion:** 2–8 frame loops at 4–8 fps through `createAmbientClock`, static under
  `prefers-reduced-motion` and while idle; Bangkok time-of-day phases.

## Considered options

- *Keep the parchment theme* — rejected: wrong tone, cannot carry faculty identity.
- *Flat non-pixel modern UI* — rejected: loses the pixel-game identity the product is built on.
- *Notched-corner pixel panels* — rejected after review: reads boxy; rounded 8/12/20 px
  corners keep the hard outline and shadow while feeling softer.
- *Hand-drawn art only* — rejected for now: code-generated art keeps one palette and is
  reproducible; a human artist can still replace sheets under `rc/` later.

## Consequences

- `.px-*` class names read like Tailwind's `px-<n>` padding (e.g. `px-card px-8`). Nothing collides today (no `--spacing-card` token, no tailwind-merge); do not add either without renaming.
- Small `.pixel-font` labels (201 usages at 5–9px) now render in Chakra Petch, whose caps are about 30% smaller than Press Start 2P. They violate design.md's 10px floor and are swept to ≥10px in the Part B screen groups.
- ADR-0019's palette, wood slabs, plum shadows and "pixel font is Latin-only display"
  rules are superseded; its game-feel principles (stepped motion, hard shadows) stand.
- Screens keep working unchanged; some now show leftovers (hard-coded hex, `text-black`,
  Tailwind palette classes) that Part B screen groups clean up.
- New contributors regenerate art with `npm run art:build` and must open
  `docs/art-review/*.png` before committing a family.
