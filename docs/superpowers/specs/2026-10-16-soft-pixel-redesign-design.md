# Soft Pixel — design system, art pipeline, legacy redesign

**Date:** 2026-10-16 · **Status:** draft for review · **Overview:** [2026-10-16-ilovetcas-v2-overview.md](2026-10-16-ilovetcas-v2-overview.md)
**Reference art:** `assets/2026-10-16-ilovetcas-v2/` (`studygram-desk-anim.webp` is the canonical "feel")

## Why

The current cozy-parchment theme (ADR-0019: parchment `#f8efd6`, plum ink, wood slabs) and the reused Sprout Lands tiles look repetitive and cannot say "this is the Medicine building". The user wants white, minimal, modern, *still* pixel, soft rather than boxy, alive, and good enough to post on a studygram account.

## Part A — the system

### Tokens (replace the `@theme` block in `src/index.css`)

| Token | Value | Role |
|---|---|---|
| `--color-paper` | `#FFFFFF` | page / sheet background |
| `--color-mist` | `#F4F3F9` | secondary surfaces, inactive slots |
| `--color-line` | `#5c4e92` | primary outline = the MBTI sprites' outline colour |
| `--color-line-soft` | `#6f63a6` | object outlines inside art, secondary borders |
| `--color-ink` | `#2B2550` | text |
| `--color-ink-soft` | `#6E6890` | secondary text |
| `--color-hairline` | `#D9D5EA` | inactive borders, dashed dividers |
| `--color-leaf` | `#5FB57A` | Leaves currency, success |
| `--color-warn` / `--color-danger` | `#E8A93B` / `#D9534F` | states |
| Zone accents | health `#E8817B`, sci `#5B8DEF`, soc `#9B7BD6`, biz `#E8A93B`, arts `#E58BC0`, earth `#5FB57A` | each with `-soft` (≈12% tint) and `-deep` |

Existing token *names* used across the app (`brand`, `ink`, `surface`, `edge`, `hud`, `wood*`…) are **re-pointed** to the new values first (zero-diff restyle), then renamed screen by screen in Part B.

### Type

- **Chakra Petch** 500/600/700 — headings, numbers, labels on game UI (has Thai, squared, reads "pixel" without being a bitmap font).
- **Noto Sans Thai** — body (unchanged).
- **Press Start 2P** — only for short Latin flourishes (e.g. `I LOVE TCAS` wordmark on the share card). Never for Thai.
- Sentence case. No all-caps labels.

### Components (`src/components/ui/`)

Restyle in place, keep APIs: `Button`, `BottomSheet`, `Popup`, `SegmentedTabs`, `SearchBar`, `SelectCard`, `SelectableRow`, `Toggle`, `PanelHeader`, `StatBadge`, `ProgressRing`, `Avatar`, `NotificationBadge`, `LoadingScene`, `DragHandle`, `StepScreen`. Replace `neo-*` CSS (`neo-card/btn/slab/sheet/pressed/input`) with `px-*` equivalents (2px line border, `--radius-ui`, `--shadow-px`, pressed = translate 2px + shadow 1px). New: `PxIcon` (renders a pixel sprite at integer scale with `image-rendering: pixelated`), `ItemSlot` (hotbar/inventory cell), `Toast`.

### Art rules ("Soft Pixel")

1. Base grid 16 px tiles; characters stay 48×48 frames. Integer scaling only.
2. Rounded corners 2–4 px on every box-like object; natural forms built from ellipses (leaf clusters, bushes, pets, bowls, domes, arched windows).
3. Outline: `#5c4e92` for silhouettes/characters, `#6f63a6` for object interiors; no pure black anywhere.
4. Palette: white/mist architecture, glass `#A4D3EC`/`#E1F3FB`, pastel accents above; light comes from one direction (top-left window), drop shadows are translucent purple `rgba(70,60,116,.15–.3)`.
5. Animation: 2–8 frames, 4–8 fps, loops offset per object so nothing pulses in sync. Tweening only for UI (sheets, pressed states).

### Art pipeline

Assets are **generated by code and reviewed by eye**, matching the brainstorm prototypes (`assets/…/prototypes/`):

- `scripts/art/px.mjs` — pixel canvas (rect, rrect, ellipse, oval, bitmap, blit, save ×N) on `sharp`.
- `scripts/art/<family>.mjs` — one generator per asset family (buildings, room furniture, pets, icons, accessories, tiles) exporting `draw(frame)`; `scripts/art/build.mjs` writes spritesheets + a JSON atlas into `public/assets/rc/` and, optionally, uploads to Storage `rc/` (owner credentials, like `uploadAssets.mjs`).
- Every generated sheet also writes a ×4 **contact sheet PNG** to `docs/art-review/` (gitignored) for visual review; an asset is "done" only after it has been opened and checked (silhouette reads at 1×, no stray pixels, palette rules met).
- Unit tests: atlas JSON shape, frame counts, no pixel outside palette (palette-lint test over generated buffers).

Existing Sprout Lands assets remain only where nothing replaces them yet; they are removed from the main app as each area is redrawn.

### Motion system

`src/game/ambient/` — small, data-driven animators (twinkle, sway, steam, shimmer, drift, pet behaviour tree) registered per scene; all subscribe to `idleGovernor` (static when hidden/AFK) and a `reducedMotion` flag. Time-of-day (Asia/Bangkok): morning / day / golden hour / night palettes applied as a tint + light-sprite swap; occasional rain on window layers.

## Testing

- Token swap: snapshot of computed colours on a sample of components; app boots with no missing CSS vars (test fails on `var(--x)` unresolved in `index.css`).
- Contrast: automated check that text tokens on `paper`/`mist`/zone-soft meet WCAG AA.
- Art: palette-lint + atlas tests; human visual review step recorded in the plan.

## Out of scope

Dark mode, new fonts beyond Chakra Petch, redesigning React Flow interaction.
