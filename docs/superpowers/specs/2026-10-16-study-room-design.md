# Study Room — Forest-style focus, Leaves, decorate & dress up

**Date:** 2026-10-16 · **Status:** draft for review · **Overview:** [2026-10-16-ilovetcas-v2-overview.md](2026-10-16-ilovetcas-v2-overview.md)
**Art:** `assets/2026-10-16-ilovetcas-v2/study-room.png`, `pets.png`, `studygram-desk*.{png,webp}`, `mockups/studygram-card.html`

## Purpose

Replace the Personal Map and Farm with the student's own **study room**. Studying (verified focus) grows a tree and earns **Leaves**; Leaves buy furniture, room expansions, room themes, pets and outfit items. Finishing a session yields a **studygram card** worth posting. The room is where the app opens.

## The room

- **Scene:** new Phaser `RoomScene` (same player controller, camera, collision approach as today). Room shell = Tiled JSON per **tier** generated by the art pipeline; furniture are sprites placed from data.
- **Tiers** (bought with Leaves, permanent):

| Tier | Size (tiles) | Price | ≈ study hours |
|---|---|---|---|
| 0 Starter | 11×9 | — | — |
| 1 Bigger room | 14×10 | 1,200 | 20 h |
| 2 Lake balcony | + balcony 6×8 | 3,000 | 50 h |
| 3 Second room (music / art corner) | + 10×9 room | 6,000 | 100 h |

- **Themes** (whole-room swap of wall, floor, trim, default fabrics): `minimal` (free), `library-wood`, `café`, `night-sky`; 1,500 each.
- **Furniture & decor** (`roomCatalog/{itemId}`): `{ name, kind: 'furniture'|'decor'|'desk'|'wall'|'pet'|'outfit'|'accessory'|'theme'|'tier', price, footprint:[w,h], spriteKey, frames, deskSlot?: bool, tierMin }`. Seeded from `src/data/roomCatalogSeed.js` (same pattern as the old farm catalog seed); admin can edit prices.
- **Desk slots:** the desk exposes 4 slots (left, centre, right, back). Items with `deskSlot: true` (lamp, mug, books, plant, laptop, highlighters…) go there; they are what the studygram card renders.
- **Decorate mode** (from the Shop item): drag to place on an 8-px grid, collision with footprints, tap to pick up/return to storage. No rotation.
- **Pets:** cat (orange / black), shiba, bunny at 600 Leaves; one active pet in v1. Behaviour tree: wander → groom → sleep on pet bed → sit beside player during focus → react to tap (heart). Shown on the card.
- **Character:** accessories (head, face, neck, back) drawn per MBTI frame layout + outfit hue (`recolorImageData`); `users/{uid}.avatar = { accessories: {head, face, neck, back}, outfitHue }`.

## Focus (extends ADR-0018 sessions)

- Start from the Focus item: duration 25 / 50 / 90 / custom 10–120 min (plus a one-off 1-min *practice focus* used only by the Guide — flexible, one-time 10 Leaves, excluded from leaderboard), mode **Strict** or **Flexible**, optional **subject** (from Plan exam subjects, see Plan spec).
- `startFocus({ mode, plannedMin, subjectKey? })` stores them on `focusActive/{uid}`; existing check-in cadence, `CHECKIN_WINDOW_MS` and `DAILY_CAP_MS` (8 h) unchanged.
- **Strict:** client reports `visibilitychange`; hidden > 10 s → `abandonFocus()`; also any lapsed check-in = withered. Withered strict session → **0 Leaves**, a withered pot on the trophy shelf.
- **Flexible:** hidden pauses the timer; away > 2 min → tree withers, but verified minutes still earn.
- **Leaves** credited in `endFocus` (Functions, transaction): `floor(verifiedMinutes × rate × completionBonus)`, rate 1 (flexible) / 1.5 (strict), completionBonus 1.1 when `verified ≥ planned`. Written to `users/{uid}.leaves` (Functions-owned; rules deny client writes, like Coins). Existing `focusXp`/MBTI multiplier/leaderboard keep working.
- **Trees:** species by planned duration (sprout <25, shrub 25–49, tree 50–89, blossom ≥90; withered variant). Stored in `focusSessions` as `{ tree, mode, subjectKey, leaves }`; the trophy shelf shows the last N, a history sheet shows all.
- **In-room feedback:** character sits at desk (reading loop + page turn), desk pot grows in 4 stages, HUD shows a large growing tree + remaining time; completion = full-grow + sparkle + leaves flying to the counter.

## Economy guardrails

- Leaves only from verified focus; never purchasable with Coins; no trading.
- All purchases via callable `buyRoomItem({ itemId })` → checks price/tier/ownership, decrements `leaves`, increments `users/{uid}.roomInventory.{itemId}` (Functions-owned).
- Client writes only `rooms/{uid}` layout `{ tier, theme, placed:[{ itemId, x, y, slot? }], petId }`; Firestore rules verify `placed` counts ≤ owned counts, `theme`/`tier`/`petId` owned. Writes debounced via `syncManager` (new `roomSync`).
- Prices live in Firestore (tunable without deploy); initial table in the catalog seed.

## Studygram card

- Offered on the completion screen and from the trophy history: **layout B** — art fills the 4:5 frame (1080×1350), big focus time bottom-right in Chakra Petch, small `day N, ilovetcas.com` tag top-left.
- Scene composed client-side on a canvas from layers: window/wall by current time-of-day → desk surface → desk-slot items the user owns → today's tree → active pet → phone face-down if strict. Pixel art at integer scale.
- Actions: Save image, Share (Web Share API Level 2 with files; fallback download). Opt-in; no real name / school by default (ADR-0018 §9). Optional toggles: show goal faculty, show streak.

## Visits

Friends visit a room via the existing Visit + presence model (room key `room`). Visitors see layout, pet, trophy shelf; they cannot edit. No chat beyond existing emotes.

## Error handling

- Function failures on purchase: toast with the reason ("ใบไม้ไม่พอ ขาดอีก 120 ใบ"), no optimistic deduction.
- Offline during focus: timer keeps running locally; check-ins retry; if the window lapses, the server outcome wins and the UI explains it ("ขาดการเชื่อมต่อเกินกำหนด ต้นไม้เลยเหี่ยว").
- Catalog missing an item referenced by a layout → item hidden, layout kept.

## Testing

- Unit: leaf formula, tree species, placement collision/grid, layout ⊆ inventory validator, card layer composition order.
- Functions: emulator tests for `buyRoomItem` (insufficient leaves, tier gating, double-spend in parallel), `endFocus` credit (strict wither = 0, flexible partial, cap), `claimWelcomePack` idempotency.
- Rules: client cannot write `leaves`/`roomInventory`/`welcomePack`; layout over-placement rejected.
- E2E (Playwright): new user → welcome pack → 1-min test focus (test hook) → leaves credited → buy lamp → place on desk → card shows lamp.

## Out of scope (v1)

Multiple pets at once, item rotation, trading/gifting, seasonal events, room-to-room portals inside a friend's house, AI-generated decor.
