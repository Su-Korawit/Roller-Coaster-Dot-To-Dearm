# Soft Pixel Part A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the cozy-parchment theme with the Soft Pixel system (tokens, type, surfaces, UI primitives, two new primitives), and add the code-generated art pipeline and the ambient-motion core that later sub-projects build on.

**Architecture:** Existing Tailwind token *names* are re-pointed to Soft Pixel values so all ~1,900 utility usages restyle with zero JSX edits; `neo-*` surface classes are restyled and given canonical `px-*` aliases (usages migrate in Part B). Art is generated by Node scripts (`scripts/art/`) on `sharp` and written to `public/assets/rc/`. Motion is two pure modules (`timeOfDay`, `ambientClock`) consumed by scenes in later specs.

**Tech Stack:** Tailwind v4 (`@theme` in `src/index.css`), React 19, Vitest 4 (+ jsdom per-file), Node ESM scripts, `sharp` 0.35.

**Spec:** `docs/superpowers/specs/2026-10-16-soft-pixel-redesign-design.md` (Part A). Overview: `docs/superpowers/specs/2026-10-16-ilovetcas-v2-overview.md`. Reference art + prototype generators: `docs/superpowers/specs/assets/2026-10-16-ilovetcas-v2/`.

## Global Constraints

- Plain JS/JSX only — no TypeScript, no tsconfig. Tailwind v4: tokens only in `src/index.css` `@theme`; no `tailwind.config.js` / `postcss.config.js`.
- Behaviour and component **APIs unchanged**; every existing test must still pass (`npm test`).
- Never put pure black in art or UI; primary outline `#5c4e92`, object outline `#6f63a6`.
- Fonts: Chakra Petch 500/600/700 for headings/numbers/game labels; Noto Sans Thai body; Press Start 2P only for Latin wordmarks (`I LOVE TCAS`, `site.pixelName`). Sentence case, no all-caps labels.
- Radii: 8px cards/buttons, 12px slots/inputs, 20px sheet top. Shadow is hard, no blur: `3px 3px 0 0 #5c4e92` (small: `2px 2px 0 0 #5c4e92`).
- Art: integer scaling only, 16-px tiles, 48×48 character frames, corners rounded 2–4 px, natural forms from ellipses.
- Motion: ambient loops 2–8 frames at 4–8 fps; static under `prefers-reduced-motion` and while `idleGovernor` reports idle.
- Text tokens must meet WCAG AA (≥ 4.5:1) on `#FFFFFF`. Where the spec's hex fails, this plan uses the darker value given in Task 2 (danger, accent-pink, biz-deep).
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Legacy hex left in `index.css`** (parchment `#f3e5c2`, plum `#90625d`, wood `#aa7959`…) — a stray one makes a screen look half-migrated. Pinned by the palette-purge test in Task 3.
2. **White text on a re-pointed `bg-brand` / `bg-warn` / `bg-good`** — e.g. `bg-warn text-white` badges become unreadable. Task 2 pins white-on-`brand`/`brand-strong`/`ink`/`danger` ≥ 4.5; `warn`/`good`/`lime` are background-only tokens and Task 2 asserts they are documented as such in the `@theme` comments.
3. **`rounded-*` utilities on `.neo-btn` / `.px-btn` losing to the class radius** — default radius must stay in `@layer components` (as today) so `rounded-full` still wins. Pinned in Task 3.
4. **Wordmark rendered in Chakra Petch** after `.pixel-font` changes family — the 11 Latin wordmark/pixelName spots must move to `.wordmark-font`. Pinned by the grep test in Task 4.
5. **Generated sprites with off-palette or semi-transparent fringe pixels** — breaks the crisp look at integer scale. Pinned by the palette lint in Task 7 and the icons build test in Task 8.
