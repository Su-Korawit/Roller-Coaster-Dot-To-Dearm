# Homepage Professionalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Idea:** `node-1-1783855059015` — Process "Homepage" (+ Process "SEO") on the IR Board.

**Requirement (from the Idea's Process notes, translated):**
1. Make every public homepage look more professional — **use real images** (not placeholders).
2. Review all written copy for tells that it was AI-written; fix it so it reads
   like a human wrote it.
3. Add a **professional footer** — with sections and links to every page — on
   every public page.
4. Add the **logo**, and the logo on the browser tab (favicon), per the attached
   image (1024×1024 illustration: student with glowing goggles, purple
   background — stored at the Idea's Image Block URL, see Task 1).
5. (SEO Process) Detailed SEO on every page so the site is findable on Google
   and every search engine. Human tasks that `/unlock-bkb` can't perform get a
   note left for the owner.

**Scope (verified against the code):** the public surface is six pages across
the multi-site router (`src/App.jsx` + `src/constants/sites.js`, ADR-0012):

| Site | Page component | Gaps found |
|------|----------------|------------|
| ilovetcas.com (hub) | `src/pages/HubPage.jsx` | no images, thin footer, no logo |
| roadmap.ilovetcas.com | `src/pages/landing/RoadmapLanding.jsx` | `pixel-checker` screenshot **placeholder** in hero |
| school.ilovetcas.com | `src/pages/landing/SchoolLanding.jsx` | same placeholder |
| tcas.ilovetcas.com | `src/pages/landing/TcasExplorerPage.jsx` | tool-first page; footer/logo only |
| news.ilovetcas.com | `src/pages/landing/NewsHomePage.jsx` | tool-first page; footer/logo only |
| app.ilovetcas.com `/` | `src/pages/WelcomePage.jsx` | thin footer, no logo (site is deliberately noindex) |

SEO today: `scripts/prerender.mjs` already emits per-site head tags, JSON-LD,
`sitemap.xml`, `robots.txt` (app site noindex by design — keep). Missing:
`og:image` / Twitter card tags, favicon/apple-touch-icon links, Organization
logo in JSON-LD, news-post URLs in the news sitemap, and search-engine
console submission (human task).

**Goal:** All six public pages ship with real product screenshots, humanized
Thai copy, one shared professional multi-column footer, the brand logo in the
nav and the browser tab, and complete OG/Twitter/sitemap SEO — verified by
`npm test` and a production build + prerender run.

**Architecture:**
- **Brand assets** live in `public/brand/` (same-origin static files — favicons
  and OG images cannot come from Firebase Storage). A one-off Node script
  `scripts/makeBrandAssets.mjs` (uses `sharp`, new devDependency) downloads the
  source illustration from the Idea's Image Block URL and emits:
  `favicon-32.png`, `favicon-192.png`, `favicon-512.png`,
  `apple-touch-icon.png` (180×180), `logo-96.png` (nav size), and
  `og-card.png` (1200×630 — illustration on the brand purple, wordmark right).
  Only the generated files are committed (keep each ≤ 200 KB), not the 1.9 MB
  source.
- **Screenshots** are captured by `scripts/captureScreenshots.mjs` (Playwright
  is already a devDependency) against the local dev server with `?site=` URLs,
  written to `public/assets/screenshots/{roadmap,school,tcas,news}.png`
  (1280×800, then sharp-compressed to ≤ 250 KB each).
- **Footer**: one new `src/components/landing/SiteFooter.jsx` replaces the body
  of `src/components/welcome/WelcomeFooter.jsx` (WelcomeFooter stays as a
  re-export so all existing imports keep working). Columns: brand (logo +
  tagline), เครื่องมือ (the four tool sites from `SITES`), ลิงก์ (แอปเต็ม /
  ข่าว / FAQ), ติดต่อ (email). Bottom bar: © year + "I LOVE TCAS". Keep the
  neobrutalist pixel-font identity — pixel-font headings, thai-font body,
  `border-t-2 border-ink bg-surface`.
- **Copy** stays where it lives today (`SITES` for landing h1/intro/description,
  component-local strings elsewhere) — this is a rewrite pass, not a refactor.
- **SEO head**: `scripts/prerender.mjs` `headTags()` gains og:image +
  twitter:card tags; `index.html` gains favicon links + `theme-color` (these
  flow into every prerendered shell since prerender reuses the built shell).
- Standing rules: no deploys (queue into `.iloveskill/pending-deploys.json`),
  no `StartNode` / user-Roadmap changes (none touched here).

**Tech Stack:** React 18 JSX (no TS), Tailwind v4 tokens from `src/index.css`,
lucide-react icons, Vitest + Testing Library, Playwright (screenshots), sharp
(new devDep, build-script only), Node ESM scripts.

## Task 6 — Humanize the copy (AI-tell pass)

Review every user-visible Thai string on the six pages against these tells and
rewrite in place. Tells to hunt: (a) the same stock phrase repeated across
pages — "ครบในที่เดียว" currently appears in hub title, hub h1, school h1,
school intro; (b) em-dash "—" chains in nearly every sentence; (c) symmetrical
triplet marketing rhythm ("ไม่ต้องสมัคร ไม่ต้องล็อกอิน ไม่มีลิมิต"); (d) generic
superlatives with no concrete detail. Rewrites must keep meaning, sound like a
Thai student/teacher wrote them, and keep head-only `title`/`description`
within SEO length (title ≤ 60 chars, description 120–158).

- [x] `src/constants/sites.js` — all six entries: `title`, `description`,
      `h1`, `intro`. De-duplicate "ครบในที่เดียว" to at most one page; vary
      sentence rhythm; cut decorative em-dashes to ≤ 1 per string.
- [x] `src/pages/HubPage.jsx` — `STEPS` copy, app band, trust strip.
- [x] `src/pages/WelcomePage.jsx` `SHOWCASE` + welcome sections
