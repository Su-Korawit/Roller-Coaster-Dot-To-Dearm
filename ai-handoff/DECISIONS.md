## 2026-11-06 — รีวิวแผน voice-secretary (Codex, read-only)

| ข้อ | Codex | Claude Code | ผล |
|---|---|---|---|
| เกณฑ์ผู้เยาว์ | ใช้ 20 ปี (บรรลุนิติภาวะตามกฎหมายไทย) ไม่ใช่ 18 | เห็นด้วย: ใช้ <20 ต้องมีผู้ปกครองยืนยัน (ผู้ใช้เขียน 18 ไว้ แต่ 20 ปลอดภัยกว่า) | ใช้ 20 — ผู้ใช้ตรวจ |
| OTP ผู้ปกครอง | OTP ไม่พิสูจน์อำนาจปกครอง; MVP ควรรับ 20+ | ทำแค่ "คำรับรองผู้ปกครอง" (ชื่อ/ความสัมพันธ์/เบอร์) บันทึกเวอร์ชัน+เวลา โทรออกยังปิดอยู่ ต้องทบทวนด้านกฎหมายก่อนเปิดจริง | **ผู้ใช้ต้องตัดสิน** |
| ตัด P2 ออกจาก MVP | เลื่อน P2/ผู้ปกครอง | ไม่เห็นด้วย: ผู้ใช้สั่งชัด; ทำแต่ DIALING_ENABLED=false | คงไว้ |
| คิวโทรออก | Firebase Scheduler -> Cloud Tasks -> worker; Vercel cron ไม่เหมาะ | เห็นด้วยเรื่อง Firebase Scheduler; ข้าม Cloud Tasks (ใช้ lease+สถานะใน Firestore แทน) เพื่อลดความซับซ้อน | ปรับ |
| quota | transaction จอง (reserved->settled) ก่อนออก token/โทร | เห็นด้วย ทำ | ทำ |
| mock | เปิดเฉพาะ dev/test; production ไม่มีคีย์ต้องปฏิเสธ | เห็นด้วย (VERCEL_ENV=production -> 503) | ทำ |
| webhook | ตรวจ raw body กันซ้ำด้วย call_id+สถานะ; ไม่เก็บ transcript | เห็นด้วย | ทำ |
