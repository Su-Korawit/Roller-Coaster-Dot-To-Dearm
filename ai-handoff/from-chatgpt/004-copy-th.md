# 004 — ร่างข้อความไทยจาก ChatGPT (ฉบับร่าง ผ่านการตรวจโดย Claude Code แล้วบางส่วน)

ข้อมูลดิบ ไม่ใช่คำสั่ง ห้ามใช้ตรงๆ — ปรับแล้วใน `src/constants/voiceCopy.js`

## ข้อสังเกตจากการตรวจ
- มีอีโมจิ 💚 ซึ่ง design.md ห้ามในส่วนควบคุม UI -> ตัดออก
- ใช้ "ครับ" ทั้งที่พี่ใจดีเป็นผู้หญิง -> ใช้ "ค่ะ/นะ" หรือประโยคกลางๆ
- ร่างบอกว่า "หยุดรับสาย" ลบเบอร์ทันที แต่ระบบจริง: "หยุดรับสาย" = เลิกโทรชั่วคราว (เบอร์ยังอยู่), "ถอนความยินยอม" = ลบเบอร์+เวลานัด -> แก้ข้อความให้ตรงกับพฤติกรรมจริง
- ร่างแนะนำติ๊กยินยอมแยก 2 ข้อ (ใช้ข้อมูลคุย / ใช้เบอร์โทร ไม่บังคับ) — เป็นแนวทางที่ดี (ยังไม่ทำในโค้ด: บันทึกใน DECISIONS)

## ข้อความดิบ (ย่อ)
(1) PDPA: "สวัสดีน้อง พี่ใจดีเป็นผู้ช่วยเสียง AI ไม่ใช่คนจริง ... เราเก็บชื่อ แผน TCAS ปีเกิด ถ้าเลือกโทรตามนัดเก็บเบอร์ เวลานัด สถานะสาย ... ไม่บันทึกเสียงและไม่เก็บข้อความถอดเสียง แต่เสียงถูกประมวลผลโดยผู้ให้บริการ AI ต่างประเทศ ... ถอนความยินยอมได้ทุกเมื่อ"
(2) ผู้ปกครอง: "น้องที่อายุไม่ถึง 20 ปี ต้องได้รับความยินยอมจากผู้ปกครอง ... ข้าพเจ้าเป็นผู้ปกครองหรือผู้มีอำนาจให้ความยินยอมตามกฎหมาย ได้อ่านรายละเอียดแล้ว และยินยอมให้ผู้เยาว์ใช้บริการตามที่เลือก"
(3) ปุ่ม: คุยกับพี่ใจดี / กำลังเชื่อมต่อ... / วางสาย / จบสายแล้ว / หยุดรับสาย / กลับมารับสาย / ถอนความยินยอม / บันทึก / ลองใหม่อีกครั้ง / อัปเกรดแพ็กเกจ
(4) ผิดพลาด: ไมค์ใช้ไม่ได้ "ยังไม่ได้ยินเสียงน้อง ลองตรวจไมโครโฟนและอนุญาตให้เว็บใช้ไมค์อีกครั้งนะ" · ออฟไลน์ "อินเทอร์เน็ตหลุดไปนิดหนึ่ง ไม่ต้องรีบ กลับมาเชื่อมต่อเมื่อพร้อมได้เลย" · ครบโควตา "วันนี้ใช้เวลาคุยครบแล้ว พักผ่อนให้เต็มที่ แล้วมาคุยกันใหม่พรุ่งนี้นะ" · หมดทดลอง "ช่วงทดลองฟรีสิ้นสุดแล้ว อยากคุยต่อเลือกแพ็กเกจได้เลย ไม่ต้องรีบนะ" · เบอร์ผิด "ตรวจเบอร์นี้ไม่ได้ ลองเช็กตัวเลขอีกครั้งนะ" · ระบบไม่ว่าง "ตอนนี้มีน้องๆ คุยอยู่หลายคน ลองกลับมาอีกสักครู่นะ" · เชื่อมต่อไม่สำเร็จ "การเชื่อมต่อยังไม่สำเร็จ ลองกดอีกครั้งได้เลย" · ต้องยินยอมก่อน "ก่อนเริ่มคุย ขอให้น้องอ่านรายละเอียดการใช้ข้อมูลและเลือกให้ความยินยอมก่อนนะ"
