# 008 — แบนเนอร์ Store 3 ใบ + ฉากเปิดแอป (Goal / Habit / Community / Reading / Secretary / Report)

อ้างอิงสไตล์: `ai-handoff/STYLE.md` (Soft Pixel) · ตอนนี้ในแอปใช้ภาพที่วาดด้วยโค้ดอยู่แล้ว (ใช้งานได้จริง) ใบสั่งงานนี้ไว้ทำภาพ AI ที่ละเอียดกว่าเพื่อมาแทนทีละชุด

## ภาพรวมทิศทาง (ใช้กับทุกภาพ)
- ภาพประกอบแนวเล่าเรื่อง คนตัวเล็กในฉากกว้าง แรงบันดาลใจจากวิดีโอ "Rise" ที่ผู้ใช้อ้างอิง แต่ต้องเป็นงานต้นฉบับ ห้ามลอกตัวละคร/ฉากจากวิดีโอ
- สไตล์ Soft Pixel: ขอบหมึกม่วงเข้ม `#463c74` พื้นที่สีเรียบ ไม่ไล่สีฟุ้ง ไม่ photoreal พาเลตสีตาม STYLE.md (ม่วง `#5c4e92`, เขียวใบไม้ `#5FB57A`, ฟ้า `#5B8DEF`, ชมพู `#E58BC0`, เหลือง `#E8A93B`)
- ตัวละครเป็นนักเรียนวัยรุ่นไทยแบบเรียบง่าย ไม่มีใบหน้าละเอียด ไม่มีตัวอักษร ตัวเลข โลโก้ ลายหมากรุก

## A. แบนเนอร์ Store (3 ใบ) อัตราส่วน 8:3 (1600x600) พื้นหลังทึบ
เว้นพื้นที่ซ้าย 40% ให้โล่ง (ข้อความจะวางทับด้วยโค้ด) ตัวฉากอยู่ขวา
1. **welcome** ภูเขาสีม่วงมีธงบนยอด ดาวระยิบ (ธีมต้อนรับ/เริ่มต้นเดินทาง)
2. **plan** ปฏิทินใหญ่มีเครื่องหมายถูก ปากกา และหนังสือกองเล็กๆ (ธีมวางแผนอ่านหนังสือ)
3. **admission** อาคารมหาวิทยาลัยมีหลังคาจั่วสีเหลือง นักเรียนกำลังเดินเข้าไป (ธีมสมัครมหาวิทยาลัย)

## B. ฉากเปิดแอป อัตราส่วน 20:13 (1600x1040) เป็นชุด 3-4 เฟรมต่อแอป (ภาพนิ่งเรียงเป็นสตอรีบอร์ด)
| แอป | เฟรมที่ 1 → ท้ายสุด |
|---|---|
| **Goal** (ไฮไลต์เหลืองในสเก็ตช์) | คนยืนอยู่ในกล่องกระดาษ → ปีนออกจากกล่อง → เดินพ้นกล่องไปหาธง/แสงสว่างไกลๆ |
| **Habit** (ไฮไลต์เขียว) | เดินขึ้นเนิน → สะดุดหินล้ม → ลุกขึ้นปัดฝุ่น → กระโดดข้ามหินได้ |
| **Community** (ไฮไลต์ชมพู) | คนติดอยู่ในหลุมคนเดียว → เพื่อนเดินมาถึงปากหลุม → เพื่อนยื่นมือดึงขึ้น → เดินไปด้วยกันเป็นกลุ่ม |
| **Reading** | นั่งโต๊ะอ่านหนังสือ โคมไฟ → เปิดหนังสือ มีนาฬิกาจับเวลา → อ่านจนวงจับเวลาครบ |
| **Secretary** | หุ่นยนต์ผู้ช่วยหน้ากลมยิ้มโบกมือ → ฟองคำพูดเป็นเช็กลิสต์ → ติ๊กถูกครบ มีหัวใจ |
| **Report** | หลอดไฟไอเดียเหนือหัวนักเรียน → ส่งซองจดหมาย/เครื่องบินกระดาษเข้ากล่องคำขอ → เพื่อนๆ ยกนิ้วโหวต → ไอคอนแอปใหม่เด้งออกมา |

## ข้อห้าม
ไม่มีข้อความ/ตัวเลข/โลโก้ใดๆ ในภาพ ไม่ลอกตัวละคร/ฉาก/แบรนด์/ผลงานที่มีเจ้าของ (รวมถึงวิดีโอ Rise) ไม่เลียนศิลปินเฉพาะราย
