# 010 — ภาพปกแอป (key art) สำหรับหน้า splash ของ 7 แอป

อ้างอิงสไตล์: `ai-handoff/STYLE.md` (Soft Pixel) · ใช้ในหน้า loading ของแอป (`src/os/splash/AppSplash.jsx`) แบบ splash ของแอปเดสก์ท็อป

## วัตถุประสงค์
ภาพโปสเตอร์ภาพเดียวต่อแอป (ไม่ใช่การ์ตูนหลายช่อง/สตอรีบอร์ด/เฟรมแอนิเมชัน) ใช้เป็นพื้นหลังเต็มจอของหน้า loading มีชื่อแอป โลโก้ และแถบโหลดวางทับด้านล่างซ้าย

## ข้อกำหนดทุกภาพ
- แนวนอน 3:2 (ได้จริง 1536x1024) พื้นหลังทึบ ไม่มีกรอบ
- สไตล์: พิกเซลอาร์ตแบบโปสเตอร์ ขอบม่วงเข้ม สีเรียบสดใสพร้อมแสงนุ่ม (Soft Pixel)
- องค์ประกอบ: ตัวเรื่องอยู่ขวาสองในสาม ซ้ายหนึ่งในสามค่อนข้างโล่งสำหรับวางชื่อ
- ห้าม: ตัวอักษร ตัวเลข โลโก้ กรอบ ลายหมากรุก ลอกตัวละคร/แบรนด์/ผลงานที่มีเจ้าของ ต้องเป็นงานต้นฉบับ

## ฉากต่อแอป
| แอป | ฉาก |
|---|---|
| goal | นักเรียนสะพายเป้บนทางขึ้นเขาตอนพระอาทิตย์ขึ้น มีธงบนยอดและดวงอาทิตย์เป็นรูปเป้าธนู |
| habit | ทางเดินหินก้อนเป็นหน้าปฏิทินตัดผ่านเนินเขาสู่พระอาทิตย์ขึ้น นักเรียนเดินอยู่ มีเปลวไฟเล็กบนหินก้อนสุดท้าย |
| reading | ห้องอ่านหนังสือกลางคืน โต๊ะไม้ โคมไฟอบอุ่น หนังสือเปิด โกโก้ หน้าต่างเห็นดาวและเสี้ยวจันทร์ ไม่มีคน |
| community | นักเรียนห้าคนหลากหลายนั่งคุยกันบนสนามหญ้ายามเย็น ฟองคำพูดรูปหัวใจ/ดาว (ไม่มีคำ) |
| secretary | หุ่นยนต์ผู้ช่วยหน้ากลมยิ้มสวมหูฟังนั่งที่โต๊ะ มีการ์ดเช็กลิสต์และปฏิทินลอย (ไม่มีคำ) |
| report | กล่องรับข้อเสนอแนะใหญ่ใจดี หลอดไฟไอเดียและเครื่องบินกระดาษบินเข้า มีนักเรียนโบกมือ |
| store | ร้านตลาดพิกเซลหลังคาลายทาง ชั้นวางไอคอนแอปสี่เหลี่ยมมุมมนมีสัญลักษณ์ (หนังสือ ปฏิทิน เป้า ฟองคำพูด) นักเรียนยืนเลือก |
