# 009 — วิดีโอฉากเปิดแอป (Goal / Habit / Community) — พรอมต์สำหรับเครื่องมือสร้างวิดีโอ AI ใดก็ได้

อ้างอิงสไตล์: `ai-handoff/STYLE.md` · ภาพนิ่งชุดเดียวกันอยู่ใน 008 (`from-chatgpt/008-intro-*.png`) ใช้เป็นภาพอ้างอิงตัวละครและฉาก

## สถานะการตรวจ (2026-11-07)
- แชต ChatGPT ของบัญชีนี้ (Plus) **ไม่มีเมนูสร้างวิดีโอ**
- **Sora ปิดบริการแล้ว:** `sora.com` ส่งไปหน้า `sora.chatgpt.com/sunset` ขึ้นว่า "Sora is no longer available. You can export your data at any time." จึงเซตอัพ Sora ไม่ได้
- **ตอนนี้ใช้วิดีโอที่ทำจากภาพ:** `node scripts/introVideoFromFrames.mjs` ทำคลิป 3 เรื่อง (ภาพจาก 008 เลื่อนกล้องช้าๆ + เฟด) เป็น `{goal,habit,community}-{wide,tall}.mp4` และลงทะเบียนใน `INTRO_VIDEOS` แล้ว ไม่ใช่วิดีโอที่ AI สร้าง ตัวละครไม่ขยับ
- ถ้าวันหน้าอยากได้วิดีโอ AI จริง ให้ใช้เครื่องมือสร้างวิดีโอเจ้าอื่น (ผู้ใช้เลือกและตรวจสิทธิ์/ราคาเอง) แล้วเอาพรอมต์ด้านล่างไปใช้ จากนั้นรัน `scripts/introVideo.mjs` ทับไฟล์เดิม ไม่ต้องแก้โค้ด

## พรอมต์วิดีโอ AI (ต่อแอป ความยาว 8-12 วินาที ไม่มีเสียง ไม่มีตัวอักษรในภาพ)
ใช้ภาพ `008-intro-<app>.png` เป็นภาพอ้างอิงให้ตัวละครเหมือนเดิม
| แอป | เรื่อง (ภาพต่อเนื่องเป็นคลิปเดียว) |
|---|---|
| goal | นักเรียนยืนในกล่องกระดาษ → ปีนออกมา → เดินตามทางไปหาธงบนเนินเขาตอนฟ้าสว่าง |
| habit | นักเรียนเดินขึ้นเนิน → สะดุดหินล้ม → ลุกปัดฝุ่น → กระโดดข้ามหิน |
| community | นักเรียนติดในหลุมตื้นคนเดียว → เพื่อน 2 คนเดินมาถึงขอบหลุม → ช่วยกันดึงขึ้น → เดินไปด้วยกัน |

ทำ 2 สัดส่วนถ้าเครื่องมือรองรับ: **16:9 (แนวนอน)** และ **9:16 (แนวตั้ง)** ถ้าได้อันเดียวสคริปต์สร้างแนวตั้งให้เอง (ภาพเล็กกลางกรอบ พื้นเบลอ)

## ข้อห้าม
ไม่มีตัวอักษร/ตัวเลข/โลโก้ในภาพ ไม่ลอกตัวละคร ฉาก หรือสไตล์ศิลปินเฉพาะราย (รวมวิดีโอ Rise) ต้องเป็นงานต้นฉบับ

## ที่วางไฟล์ในโปรเจกต์ (ทำโดย Claude Code หลังรีวิว)
1. วางไฟล์ต้นฉบับใน `ai-handoff/from-chatgpt/009-<app>-wide.mp4` (และ `009-<app>-tall.mp4` ถ้ามี)
2. รัน `node scripts/introVideo.mjs <app> <wide.mp4> [<tall.mp4>]` ได้ `public/assets/os/intro/<app>-wide.mp4` (960px) และ `<app>-tall.mp4` (540x960) H.264 ไม่มีเสียง ราว 1-2MB ต่อไฟล์
3. เพิ่ม id ใน `INTRO_VIDEOS` ที่ `src/os/intro/introLogic.js` (เทสต์จะเช็กว่ามีไฟล์ครบทั้งสองขนาด)
4. ตัวเล่น (`AppIntro.jsx`) เลือกไฟล์ตามแนวจอ เล่นแบบ muted + playsInline อัตโนมัติ ใช้ภาพนิ่งเฟรมแรกเป็น poster และเวลาคำบรรยายแบ่งตามความยาวคลิป ถ้าผู้ใช้ตั้งลดการเคลื่อนไหว หรือไฟล์โหลดไม่ได้ จะกลับไปใช้ภาพนิ่งชุดเดิมอัตโนมัติ
