# I LOVE TCAS — Chrome extension

เปิด I LOVE TCAS เป็นแผงข้างจอ (Side Panel) ข้างเว็บ MyTCAS / เว็บมหาวิทยาลัย โดยไม่ต้องสลับแท็บ
และมีแถบลัดบางๆ ด้านล่างของหน้าเว็บเหล่านั้น (ซ่อนได้ด้วย ×)

## ลองใช้ (ยังไม่ขึ้น Web Store)
1. เปิด `chrome://extensions` แล้วเปิด **Developer mode**
2. กด **Load unpacked** แล้วเลือกโฟลเดอร์ `extension/`
3. กดไอคอนส่วนขยายเพื่อเปิดแผงข้างจอ หรือเข้า https://www.mytcas.com/ แล้วกดแถบลัดด้านล่าง

พัฒนากับ dev server: แก้ `APP_URL` ใน `config.js` เป็น `http://localhost:5173/` แล้ว Reload ส่วนขยาย

## ทำงานยังไง
- แผงข้างจอแคบ เว็บเราจึงแสดงเลย์เอาต์แบบมือถืออัตโนมัติ
- แผงนำทางไปที่เว็บเราโดยตรง (ไม่ใช้ iframe) เพื่อให้ล็อกอิน Google และจำการล็อกอินได้เหมือนแท็บปกติ
- แถบลัดเปิดแอปด้วย `?open=<app id>` (ดู `src/os/deepLink.js`)
- สิทธิ์ที่ขอ: `sidePanel`, `storage` (จำหน้าที่จะเปิด) และฝังแถบลัดเฉพาะ `mytcas.com` กับ `*.ac.th` แถบลัดไม่อ่านเนื้อหาหน้าเว็บ

## ข้อจำกัด
- ใช้ได้กับ Chrome/Edge 116 ขึ้นไป (Side Panel API)
- ยังไม่ได้ทดสอบโหลดจริงใน Chrome ในรอบนี้ โปรดทดลองตามขั้นตอนด้านบนก่อนปล่อย
- ไม่ฝังแถบด้านบนของเว็บอื่น เพราะเลื่อนหน้าเว็บของเขาเสี่ยงทำ layout พัง ถ้าต้องการค่อยเพิ่มภายหลัง
